# Chatbot-Styled-Tutor
#this is just a test!
This repo is for iFp students developing there own Chatbot Tutor. You will find an index, styles, and script that will help you set up your chatbot. Your goal is to continue to adapt, modify, and style your chatbot to be able to teach about a subject/topic of interest.

You should pull the repo through the terminal using Git or download the repo onto you machine and pull the file on to your desktop to work on. If you are pulling from Github, make sure to make a new branch so you can modify your own work.
